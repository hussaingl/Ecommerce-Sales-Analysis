## Overview

This folder contains the Power BI dashboard developed for the E-commerce Sales Analysis project.

## Dashboard Features

- KPI Cards
  - Total Revenue
  - Total Profit
  - Total Orders
  - Total Quantity

- Sales Analysis
  - Revenue by Region
  - Revenue by Product Category
  - Monthly Sales Trend

- Customer Analysis
  - Top Customers
  - Customer Segment Analysis

- Interactive Features
  - Year Slicer
  - Region Slicer
  - Category Slicer

## Skills Demonstrated

- Power BI
- Data Modeling
- DAX Measures
- Data Visualization
- Interactive Dashboard Design
- Business Intelligence
